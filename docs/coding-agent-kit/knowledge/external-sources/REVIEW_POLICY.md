## 5. 审核方式选择

请选择一种主审核方式，也可以定义混合方案。未选择前不得自动计算总分。

- [ ] A. 纯门禁制：所有硬性门禁通过才允许采纳，不计算分数。

- [ ] D. 双轨制：官方文档与社区代码采用不同规则。

## 16. 自动化边界

在本政策获得维护者批准前，自动化只能检查事实结构，例如：

- ID 和 URL 唯一；
- URL 使用 HTTPS；
- 引用的 review 文件存在；
- 状态值属于已声明枚举；
- 必填元数据字段存在。

自动化目前不得：

- 自动计算来源质量总分；
- 根据未批准阈值改变状态；
- 自动晋升到 `topics.json`；
- 将官方所有权、star 数、更新日期或搜索排名转换为采纳结论。
