# Completed external source reviews

One file in this directory represents one source at one commit, tag, release, or documentation date.
A review does not make every pattern in the source authoritative. Its `Approved use` section defines the
exact boundary a coding agent may rely on.

The initial 64 reviewable sources are complete. Their terminal states and collection actions are recorded
in `../sources.json` and summarized in `../REVIEW_QUEUE.md`; the discovery-only meta index intentionally has
no review file. Future sources are still reviewed one at a time so search breadth is never confused with
evidence quality.
